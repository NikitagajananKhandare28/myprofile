# Requirements matrix (product brief vs build)

## Done
Splash, welcome, phone OTP with resend timer, basic profile, profile types managed by admin, suggested sections, About, Skills, Education, Experience, Services, Achievements, Videos (links with thumbnail), Portfolio, Awards and certificates (text), Social links, Contact with per-field visibility, photo and gallery with captions, compression, rotate, square crop and reorder, per-user photo limit and usage, preview, publish and unpublish (server-side), auto-update of the public page, share link, WhatsApp, QR, link-preview page, public page, username links with alternatives, privacy switches, under-18 contact lock and consent checkbox, dashboard (completion, views, storage), settings, account deletion (server-side), report profile, admin dashboard (reports, users, analytics and storage, types, messages, limits, audit log), backend with rate limiting and server-side authorisation, privacy policy and terms templates, deletion page, automated tests (Android unit, backend unit, security-rules).

## Not built
- Video file upload (links only) and certificate file attachments (image or PDF).
- Server-side enforcement of storage limits (limits are enforced by the app).
- Drag-and-drop reorder (move up and down is provided), free-form crop (square crop and rotate provided).
- Numeric profile ID fallback, View/Search profiles, downloadable digital card (all optional or Phase 2).
- Block/Restrict mechanism for visitors.
- UI/UX designs and clickable prototype (needs a design tool).
- Marathi and Hindi translations (architecture ready, English only).
- Admin multi-factor sign-in and hosting of the admin app.
- Verified backup restore, Play Store release and real SMS delivery tested end to end.
